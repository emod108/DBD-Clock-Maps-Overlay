This program allows you to easily overlay Dead by Daylight clock maps over any other desktop application including the game itself.
After choosing a map you can set its position on your screen, size and opacity.

In case I'm too slow to update, you can select your own images. PNGs with transparent parts are also supported.
Download link can be found in Releases. Currently updated for Dead by Daylight 10.2.2

Clockmaps by Hens333: https://hens333.com/callouts

![image](https://github.com/emod108/DBD-Clock-Maps-Overlay/assets/91344595/30d10a06-1227-4944-b882-a4ee567dea6b)

Made using C++ and Qt Framework. No AI was used.

Known issues:
1) Overlay won't show up if you play in fullscreen mode. You must use windowed fullscreen or windowed modes. I don't know how to fix it.
